# 宿主连接、回调与本地独立

依据[宿主连接根 ADR](../../../decisions/desktop/cloud-connection/0-host-owned-cloud-connection-and-session.md)。
ADR 为 `approved`，尚无新增承诺的直接实现证据；下列义务均为 `Missing`。

## Local Work Remains Available Across Every Cloud Failure

- 风险：Cloud 状态错误地成为本地启动/Agent 的准入条件。
- 前置状态：本地工作区、编辑和模型连接；分别未配置 server、未登录或已登录。
- 触发：离线、认证/Cloud 故障、证书/版本不兼容、会话失效、停用及启动/唤醒。
- 必须成立：本地启动、Agent、编辑、工作区和运行可用；恢复异步；云端入口就地修复。
- 禁止结果：本地等待 Cloud、普通资源 403 被误判停用、反复登录弹窗。
- 决策依据：ADR D1、D5，不变量 1、5。

### 验证义务与证据

| 验证义务 | 代表性证据 | 状态 |
| --- | --- | --- |
| 三平台正式包在所有失败条件下启动、本地编辑与真实 Agent 运行正常 | 尚无对应故障矩阵 | `Missing` |
| 错误原因区分、恢复异步且不重放消息/任务 | 尚无宿主集成证据 | `Missing` |

## Only The Host Owns Secrets And A Single Login Transaction

- 风险：多窗口分别续期、插件取得凭据、安全存储失败后明文回退。
- 前置状态：同安装实例两个窗口、普通插件、可注入失败的系统安全存储。
- 触发：并发登录/续期、重启、存储锁定或不可用。
- 必须成立：宿主唯一所有者协调事务/续期/账号状态，插件仅得受限操作；存储失败说明修复路径。
- 禁止结果：插件读秘密、两个账号事实来源、明文配置回退、秘密进入日志/诊断。
- 决策依据：ADR D2、D3、D5，不变量 2、4。

### 验证义务与证据

| 验证义务 | 代表性证据 | 状态 |
| --- | --- | --- |
| 三平台系统安全存储、失败处理及秘密输出检查 | 尚无直接证据 | `Missing` |
| 跨窗口/进程唯一登录与续期所有者，插件不能读取秘密 | 尚无并发/权限测试 | `Missing` |

## Callbacks Cannot Change The Initiating Server Or Transaction

- 风险：回调目标替换、deep link 劫持、重放和跨部署换票。
- 前置状态：两个部署、多个实例、开发与正式包，已协商 loopback 或 deep link。
- 触发：正确/未知/过期/重复/并发及错误 state、PKCE、身份、目标回调；期间切换目标。
- 必须成立：只有原事务所有者向原验证目标换票；切换取消事务；错误回调拒绝。loopback 只监听
  回环 IP、动态端口，限制路径/次数，成功、取消和超时释放监听。
- 禁止结果：回调 URL 改换票目标、处理中随意换回调方式、长期秘密进入 URL。
- 决策依据：ADR D3，不变量 2、3。

## Transport Trust And Deployment Identity Are Checked Independently

- 风险：相同 ID、TLS 绕过或重定向把旧秘密送到其他目标。
- 前置状态：可信 HTTPS、自签/私有 CA、变化证书、HTTP、不同身份及同 ID 换密钥端点。
- 触发：首次配置、改地址、挑战重放、跨源跳转和旧地址不可达。
- 必须成立：先传输信任后身份挑战；TOFU 明确确认；同 ID/公钥且兼容才沿用有效会话，过期重登。
  失败保留记录；HTTP 持续提示；浏览器证书信任独立处理；配置不依赖旧址或市场源。
- 禁止结果：旧秘密给新身份、失败覆盖配置、签名豁免 TLS、宿主绕过浏览器、宣称 HTTP 防透明转发。
- 决策依据：ADR D3–D4，不变量 3。

## Normal Activity And Recovery Obey The Server Policy

- 风险：后台制造活动、休眠误清凭据、恢复绕过失效复核。
- 前置状态：正常客户端，有前台操作/编辑/查看 Agent、后台任务/心跳、休眠与网络故障。
- 触发：空闲到期、轮换中崩溃、联网恢复、撤销/停用、已知到期。
- 必须成立：只汇总正常前台活动，不采集键鼠内容；按服务端政策执行；恢复先复核；网络/5xx 保留资格。
  在线失效检测至多 60 秒，无法复核则停云端使用；离线缓存标记离线。
- 禁止结果：心跳/续期自身计活动、客户端延长绝对上限、要求 Gateway 识别伪造活动、循环开浏览器。
- 决策依据：ADR D5，Gateway ADR D4–D6。

## Switching Accounts Fences Old State And Preserves Local Work

- 风险：旧响应污染新账号、草稿隐式上传、退出误删现场或影响其他设备。
- 前置状态：旧上下文有缓存、订阅、未发送内容与远端任务；新 server/账号待登录。
- 触发：确认切换、切换失败、显式/离线退出、被动失效及同账号重登。
- 必须成立：清旧资格/私有缓存、终止订阅/登录事务，隔离迟到响应；失败仍本地可用。
  被动失效保留现场和原归属，显式退出不删除本地文件；离线退出说明远端撤销未确认。
- 禁止结果：自动恢复已清凭据、未发送内容给新账号、改 Git/模型/Agent 身份、退出其他设备或主动取消远端任务。
- 决策依据：ADR D6，不变量 4、6。
