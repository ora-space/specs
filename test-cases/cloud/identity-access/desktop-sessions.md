# Gateway 原生会话、部署身份与策略

依据[部署绑定 Desktop 会话 ADR](../../../decisions/cloud/identity-access/20261019-deployment-bound-desktop-sessions.md)。
新增协议尚未实现，直接证据全部 `Missing`；既有 browser-session 用例不变。

## Challenges Prove One Deployment Without Old Credentials

- 风险：把不可信能力声明、相同 ID 或重放签名当身份。
- 前置状态：两个部署、同 ID 换密钥副本、过期挑战、缺能力的旧 Gateway。
- 触发：发现、TOFU、改地址、签名/传输失败及重定向。
- 必须成立：探测不带旧秘密，签名覆盖新 nonce/ID/协议上下文并验证时效；只关联原签名身份，
  失败保留配置，会话数据丢失不能仅凭部署身份复活会话；缺能力说明升级方向。
- 禁止结果：只同 ID 就发送旧秘密、签名豁免 TLS、导出 Cookie/JWT 降级。
- 决策依据：ADR D1–D2，不变量 2。

## A Browser Approved Handoff Creates At Most One Native Session

- 风险：伪造账号、并发重放换票、开放回调及秘密出现在 URL。
- 前置状态：已有网页会话或需外部登录，两个 Gateway 副本共享 PG，原生事务有完整绑定。
- 触发：默认 2 分钟交接码正常/过期/跨部署/绑定不符/并发换票，以及响应丢失。
- 必须成立：网页批准目标/账号且受同源保护；原子消费与建会话至多一次；provider code 不直接给 Desktop；
  PG 不保存原始秘密，Cloud 不接收原生秘密；失败不重复创建，网页会话保持独立。
- 禁止结果：重复消费创建第二会话、长期秘密入 URL/日志/Cloud、导出网页 session。
- 决策依据：ADR D3，不变量 1、3。

## Database Time And Current Policy Govern Native Expiry

- 风险：破坏浏览器 TTL、客户端时间/迟到活动复活会话、多副本政策不一致。
- 前置状态：默认 30 天空闲/无绝对上限原生会话，部署覆盖缩短期限/绝对上限，已有浏览器会话。
- 触发：活动迟到/乱序/重放、跨副本续期、政策改变、到期后活动与时钟漂移。
- 必须成立：PG 当前时间/状态/政策决定期限，有效活动只推进空闲期限且不越绝对上限；
  缩短策略按当前规则重判，扩展不能复活；浏览器/provider 政策和旧行语义保持。
- 禁止结果：普通读取自动续闲、客户端时间授权延寿、Desktop 无上限套给浏览器。
- 决策依据：ADR 继承表、D4，不变量 4、6。

## Rotation Recovery Is Finite Idempotent And Revocation Aware

- 风险：丢响应无法恢复、旧凭据永久可用、重试无限展期或并发分支。
- 前置状态：协议明确有限窗口、恢复秘密归属与代次，宿主有持久恢复状态，多副本并发。
- 触发：提交前/后失败、响应丢失、新资格落盘前崩溃、双窗口续期、超窗及恢复中失效。
- 必须成立：同逻辑续期幂等，不同绑定拒绝；代次隔离，旧资格只供限定恢复；重试不延长窗口；
  最终一个当前代次或明确重登，撤销/过期/停用始终优先。
- 禁止结果：旧凭据无限业务访问、恢复复活会话、5xx 清凭据、为重放长期保留明文秘密。
- 决策依据：ADR D5，不变量 4–5。具体机制待协议 ADR，不声称已选定。

## Revocation And Disable Stop Native Use Within The Online Bound

- 风险：长连接/内部 JWT 缓存忽略撤销，资源 403 被当停用，存储拆分漏掉管理撤销。
- 前置状态：多设备、网页、Gateway 多副本/长连接，Cloud 有当前用户和资源权限。
- 触发：单设备退出、管理性撤销、停用、资源撤权、到期、复核故障与联网恢复。
- 必须成立：每次受保护请求检查，在线至多 60 秒检测含长连接；恢复先复核，复核不计活动；
  资源无权与停用区分，单设备退出独立，管理性撤销覆盖原生类型；离线如实提示。
- 禁止结果：借内部 JWT 越过时限、离线声称知悉撤销、故障仍云端操作、断连主动取消服务端任务。
- 决策依据：ADR D6，不变量 1、4、6–7。

## Every Stage Preserves Local Independence And Trust

- 风险：首阶段省略身份绑定，或 HTTP 支持顺手放开 dev provider/所有 Cookie。
- 前置状态：三个阶段能力组合、旧客户端/Gateway及部署外部 provider。
- 触发：协商缺能力、自签变化、显式 HTTP、provider 拒绝 callback、旧址不可达迁移。
- 必须成立：各阶段本地独立/身份/失效前提不变；能力如实公布；HTTP 显式配置并与
  浏览器/Cookie/provider 契约相容；最低版本取实际发布。
- 禁止结果：隐式 development/任意身份 provider、降低其他部署 HTTPS、HTTP 签名冒充加密、虚构发布证据。
- 决策依据：ADR D7，不变量 2–3、7。
